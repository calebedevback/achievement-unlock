# achievement-unlock

Repositório pessoal para experimentar e desbloquear os [GitHub Achievements](https://github.com/achievements) — badges concedidos por atividades como pull requests, colaboração e uso de funcionalidades da plataforma.

## Conteúdo

- `hello.md` — referente ao achievement **Pull Shark** (contribuições via pull request).
- - `pair.md` — referente ao achievement **Pair Extraordinaire** (commits com co-autoria).
 
  - Sinta-se à vontade para abrir uma PR e colaborar por aqui.
